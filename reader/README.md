# ورق — کتاب‌خوان بنفش با ورق‌خوردن واقعی

یک وب‌اپ سبک (HTML/CSS/JS خالص، بدون وابستگی و بدون مرحله build) برای خواندن کتاب‌هایی که می‌توانند متن، تصویر و ویدئو داشته باشند. مهم‌ترین ویژگی آن **انیمیشن ورق‌خوردن واقعی** است: با انگشت از گوشه صفحه می‌گیرید و صفحه مثل کاغذ تا می‌خورد و برمی‌گردد.

**اجرا:** پوشه را روی یک سرور ساده باز کنید (`npx serve reader` یا GitHub Pages). `index.html` اپ را داخل موکاپ آیفون با فهرست امکانات نشان می‌دهد؛ `app.html` خود اپ است (برای نصب روی گوشی همین را باز کنید). برای پخش ویدئوها اینترنت لازم است.

## امکانات

- **کتابخانه** با جلدهای تولیدشده، برچسب نوع محتوا (متن / تصویر / ویدئو) و درصد پیشرفت مطالعه (در `localStorage` ذخیره می‌شود).
- **ورق‌خوردن واقعی (page curl):** کشیدن با انگشت یا ماوس، ضربه روی حاشیه صفحه، کلیدهای جهت‌دار / Space، و دکمه‌های قبل و بعد. رها کردن در نیمه راه، ورق را به نزدیک‌ترین حالت می‌برد؛ حرکت سریع (flick) هم شناسایی می‌شود.
- **چیدمان خودکار:** تک‌صفحه روی موبایل (پشت ورق، کاغذ نیمه‌شفاف است و متن از پشت دیده می‌شود)، دوصفحه‌ای روی تبلت و دسکتاپ (پشت ورق، واقعاً صفحه بعدی است). با دکمه چیدمان می‌توان دستی تغییر داد.
- **راست‌به‌چپ و چپ‌به‌راست:** کتاب فارسی از سمت چپ ورق می‌خورد، کتاب انگلیسی از سمت راست.
- **صفحه‌بندی خودکار:** متن بر اساس اندازه صفحه و فونت به صفحه‌ها تقسیم می‌شود؛ پاراگراف‌های بلند روی مرز کلمه شکسته می‌شوند و جای مطالعه بعد از تغییر اندازه حفظ می‌شود.
- **تنظیمات:** اندازه متن، حالت شب، چیدمان. ویدئوها هنگام ورق‌زدن متوقف می‌شوند.

## روایت صوتی (متن همراه صدا)

کتاب‌هایی که `narration: 'assets/audio/<id>'` دارند، در نوار بالای کتاب دکمه هدفون می‌گیرند: صدا پخش می‌شود، کلمه در حال خواندن روشن می‌شود و وقتی گوینده به صفحه بعد برسد، صفحه خودش ورق می‌خورد. روی صفحه‌ای بدون متن (مثل ویدئو) صدا منتظر می‌ماند تا ورق بزنید.

ساخت صدا و زمان‌بندی کلمه‌ها: `python3 tools/narrate.py <book-id>` — به‌صورت پیش‌فرض از صداهای فارسی Microsoft Edge (بسته `edge-tts`، رایگان) استفاده می‌کند و `assets/audio/<id>.mp3` و `.json` می‌سازد؛ با `--engine eleven` از ElevenLabs (صدای «میترا») استفاده می‌شود. نیاز به `ffmpeg` دارد.

## ساختار

```
index.html             صفحه نمایش: موکاپ آیفون + فهرست امکانات
app.html               اپ: کتابخانه + صفحه مطالعه (PWA)
assets/css/reader.css  تم بنفش، صفحه‌ها، سایه‌های ورق
assets/js/books.js     کتاب‌های نمونه (بلوک‌های متن / تصویر / ویدئو)
assets/js/flip.js      موتور ورق‌خوردن (PageCurl)
assets/js/app.js       کتابخانه، صفحه‌بندی، حرکات لمسی، تنظیمات
```

### افزودن کتاب

در `assets/js/books.js` یک شیء به `BOOKS` اضافه کنید:

```js
{ id: 'my-book', lang: 'fa', title: '…', author: '…', color: '#5b2a86', color2: '#c084fc', kind: ['text'], minutes: 10, blurb: '…',
  blocks: [
    { t: 'h', text: 'فصل اول' },
    { t: 'p', text: 'متن پاراگراف…' },
    { t: 'quote', text: 'مصرع اول\nمصرع دوم' },
    { t: 'img', src: 'assets/img/photo.jpg', caption: '…' },   // یا svg: '<svg…>'
    { t: 'video', src: 'https://…/clip.mp4', poster: '…', caption: '…' },
    { t: 'sep' }
  ] }
```

### موتور ورق‌خوردن چگونه کار می‌کند

هندسه در یک دستگاه «محلی» حساب می‌شود که عطف کتاب در `x = 0` و لبه آزاد در `x = W` است. گوشه گرفته‌شده `C` با انگشت به نقطه `F` می‌رود (با این قید که کاغذ کش نمی‌آید). خط تا، عمودمنصف `CF` است. بخش بلندشده صفحه، **بازتاب** صفحه نسبت به این خط است که با `clip-path: polygon()` بریده و با یک `transform: matrix()` جابه‌جا می‌شود؛ سه گرادیان سایه (روی صفحه زیرین، روی خمِ جلو و روی پشتِ بلندشده) حس حجم می‌دهند. صفحه‌هایی که عطفشان سمت راست است با یک آینه‌سازی (`M`) به همین دستگاه برده می‌شوند. در حالت دوصفحه‌ای محتوای پشت ورق، صفحه بعد است و تبدیل آن `R ∘ Mx` (آینه افقی و سپس بازتاب) می‌شود که در عمل یک دوران است و متن بدون آینه‌شدن دیده می‌شود.
