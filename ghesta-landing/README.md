# لندینگ جدید قسطا

پیاده‌سازی ایستای PRD لندینگ قسطا: صفحهٔ اصلی (`index.html`) و لندینگ اختصاصی مشاوره جنگ (`war-advisory.html`).
تم روشن، راست‌چین کامل، موبایل‌محور. بدون build؛ فقط HTML/CSS/JS.

```bash
cd ghesta-landing && python3 -m http.server 8000
```

## چه چیزی کجاست؟
| فایل | توضیح |
|---|---|
| `config.js` | **همهٔ تنظیمات قابل‌تغییر**: آدرس وب‌اپ، deep link سرویس‌ها، نرخ محاسبه‌گر، APIها، نشان‌های اعتماد، بنرهای هیرو |
| `index.html` | صفحهٔ اصلی با ۱۲ بخش PRD |
| `war-advisory.html` | لندینگ مشاوره جنگ (آدرس پیشنهادی: `/war-advisory`) |
| `css/style.css` | استایل مشترک؛ رنگ‌های برند در `:root` |
| `js/common.js` | لینک‌های وب‌اپ + حفظ UTM، رویدادهای Analytics، هدر و منو، نشان‌های اعتماد |
| `js/home.js` | اسلایدر هیرو، موکاپ داشبورد، تب‌ها، قیمت طلا/کش‌بک از API، محاسبه‌گر |

## بنرهای هیرو
اسلاید اول همیشه هیروی اصلی (تیتر + موکاپ داشبورد) است. بنرهای بعدی از `heroBanners` در `config.js` می‌آیند:
- بنر با متن: `image` + `eyebrow`/`title`/`text`/`cta` (تصویر سمت چپ، متن سمت راست)
- بنر آماده و تمام‌عرض: `fullImage: true` + `image` (و `mobileImage`)
- لینک‌های `app:/...` خودکار به وب‌اپ با UTM تبدیل می‌شوند.
- نمایش خودکار دکمهٔ توقف دارد، با hover/فوکوس متوقف می‌شود و با «کاهش حرکت» سیستم‌عامل خودکار پخش نمی‌شود.

## Analytics
رویدادها در `window.dataLayer` ثبت می‌شوند (سازگار با GTM). برای دیدن آن‌ها در کنسول، `?debug_analytics` را به آدرس اضافه کنید.
`cta_login_click`، `service_card_click`، `tab_view`، `calculator_change`، `war_advisory_click`، `merchant_signup_click`، `faq_open`
