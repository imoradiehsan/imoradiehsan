# لندینگ خدمات مالی — آرکا فایننس

صفحه فرود تک‌صفحه‌ای، راست‌چین و واکنش‌گرا برای خدمات مالی و بروکری. بدون نیاز به build؛ فقط فایل‌های HTML/CSS/JS.

## اجرا
فایل‌ها را روی هر هاستی آپلود کنید یا به‌صورت محلی اجرا کنید:

```bash
cd finance-landing && python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

## تغییر بنرهای هیرو
1. تصویر بنر را در پوشه `assets/banners/` قرار دهید (اندازه پیشنهادی ۱۶۰۰×۷۰۰، و در صورت نیاز یک نسخه موبایل ۸۰۰×۱۰۰۰).
2. فایل `banners.js` را باز کنید و یک آیتم به لیست `HERO_BANNERS` اضافه/حذف/ویرایش کنید.
3. اگر متن روی خود تصویر طراحی شده، `textOnly: true` بگذارید تا فقط تصویر (با لینک) نمایش داده شود.
4. سرعت تعویض بنرها با `HERO_INTERVAL` تنظیم می‌شود.

> نکته: در بنرهای دارای متن، سمت راست تصویر را خلوت نگه دارید، چون متن آنجا قرار می‌گیرد.

## ساختار
| فایل | توضیح |
|---|---|
| `index.html` | محتوای صفحه (خدمات، حساب‌ها، پلتفرم‌ها، پروموشن، چرا ما، مراحل، نظرات، FAQ، فوتر) |
| `styles.css` | استایل‌ها؛ رنگ‌های اصلی در `:root` بالای فایل |
| `main.js` | اسلایدر، تیکر قیمت (نمایشی)، شمارنده‌ها و انیمیشن‌ها |
| `banners.js` | تنظیمات بنرهای هیرو |
| `assets/fonts` | فونت وزیرمتن (لایسنس OFL) |

## نکات
- نام برند «آرکا فایننس»، اعداد حساب‌ها، نظرات کاربران و قیمت‌های تیکر **نمونه/نمایشی** هستند و باید با اطلاعات واقعی جایگزین شوند.
